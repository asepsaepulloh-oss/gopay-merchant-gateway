Konfigurasi Callback
Tautan URL pada server/toko online Anda (misal: WHMCS, WooCommerce, Custom API) yang akan menerima laporan data transaksi secara otomatis saat pembayaran dinyatakan lunas.
Jika diaktifkan, server kami akan langsung mengirimkan notifikasi instan berupa HTTP POST payload (disertai HMAC signature pengaman) ke URL Callback Anda setiap kali ada transaksi GoPay sukses yang cocok.
